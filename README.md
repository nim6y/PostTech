# PostTech — Единая цифровая HR-платформа

Прототип единой цифровой HR-платформы, разработанный в рамках хакатона PostTech.

## Идея

Объединить распределённые HR-сервисы в единое цифровое пространство:
- **Работник**: просмотр личного профиля, создание заявки на отпуск/аванс, статусы и история, назначенные курсы и прогресс, уведомления, AI Jana. 
- **Руководитель**: видит только закреплённую за ним команду и её заявки; одобряет/отклоняет заявки своей команды; может просматривать прогресс обучения команды. Не может менять официальный профиль сотрудника.
- **HR/Администратор**:  видит все заявки в режиме мониторинга; управляет ролями демонстрационных пользователей; назначает курсы; просматривает подготовленную базу знаний и точки интеграции. Нет кнопок повторного одобрения заявок.
- **Официальные кадровые атрибуты read-only.** Это прямо следует из презентации: пользователь не должен менять кадровые данные напрямую. В промышленной архитектуре их источником будет 1С:ЗУП. Исправления проходят через установленный процесс HR, а не редактирование полей в кабинете.

2. Backend — Python, FastAPI

## Реализованные сценарии

1. Вход и разделение ролей на уровне интерфейса и API.
2. Профиль: Ф.И.О., компания, должность, подразделение, руководитель, дата приёма, остаток отпуска.
3. Заявка на отпуск: выбор периода через календарные поля, автоматический подсчёт календарных дней, запрет периода длиннее остатка на клиенте и сервере; также есть сценарий заявки на аванс.
4. Единый список заявок, карточка заявки, история обработки и уведомления о статусе.
5. Руководитель видит только заявки своей команды и принимает решение один раз.
6. Jana Academy: назначенные курсы, просмотр материала-уроков, прогресс и результат.
7. HR назначает курс сотруднику; назначение создаёт уведомление.
8. AI Jana ищет ответ только в локальной подготовленной базе знаний, показывает источник и сообщает об отсутствии надёжного ответа, если совпадение не найдено.
9. HR-панель ролей и точек будущих интеграций с 1С:ЗУП и Documentolog.

## Что реализовано / смоделировано / не входит в MVP

- **Реализовано в прототипе**: API-вход, ролевые проверки, тестовые сценарии заявок, календарный выбор периода, проверка остатка отпуска, решения руководителя, уведомления, курсовой прогресс, локальный поиск по базе AI Jana, назначение обучения и управление демо-ролями.
- **Смоделировано**: кадровые данные, учётные записи, состояние заявок, уведомления, прогресс курсов, 1С:ЗУП, Documentolog. Хранилище находится в памяти процесса и сбрасывается при перезапуске контейнера.
- **Не входит**: корпоративный SSO, реальная интеграция 1С:ЗУП/Documentolog, юридически значимый документооборот, полноценная LMS, реальная LLM, production-БД, аудит и уведомления по внешним каналам.

## Быстрый запуск

Для запуска потребуется Docker и Docker Compose.

```bash
docker compose up --build
```

Откройте http://localhost:8000 
Swagger API: http://localhost:8000/docs 
Проверка состояния: http://localhost:8000/api/health

Приложение после первого запуска работает без внешних API и без сетевых вызовов для бизнес-логики. Шрифт подключается через Google Fonts, но если сеть недоступна, интерфейс использует системные sans-serif шрифты.

Если необходим запуск без Docker. 

Python 3.12+:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

## Демо-учётные записи

Все данные синтетические, пароли предназначены только для демонстрации:

| Роль | Логин | Пароль |
|---|---|---|
| Сотрудник | `aliya` | `Employee2026!` |
| Руководитель | `daniyar` | `Manager2026!` |
| HR / администратор | `madina` | `Hr2026!` |

Дополнительный синтетический сотрудник `timur` / `Employee2026!` нужен для демонстрации командной очереди.

## Проверка

- Health endpoint: `GET /api/health`
- Swagger UI: `http://localhost:8000/docs`
- Для проверки ограничений можно войти как сотрудник и запросить `/api/hr/overview` — API вернёт `403`. HR не может вызвать решение по заявке: `/api/requests/{id}/decision` доступен только роли руководителя.
