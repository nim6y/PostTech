## Быстрый запуск

Для запуска потребуется Docker и Docker Compose.

```bash
docker compose up --build
```

Откройте http://localhost:8000. Swagger API: http://localhost:8000/docs. Проверка состояния: http://localhost:8000/api/health.

Приложение после первого запуска работает без внешних API и без сетевых вызовов для бизнес-логики. Шрифт подключается через Google Fonts, но если сеть недоступна, интерфейс использует системные sans-serif шрифты.

Если необходим запуск без Docker. 

Python 3.12+:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

## Ролевая модель

| Роль                 | Возможности                                      |
|----------------------|--------------------------------------------------|
| Работник             | Просмотр профиля, заявки, обучение, AI-ассистент |
| Руководитель         | Всё выше + управление заявками, просмотр данных  |
| HR/Администратор     | Всё выше + согласование заявок подчинённых       |
