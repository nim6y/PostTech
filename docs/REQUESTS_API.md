# Заявки сотрудника — API v1

## Маршрут
Сотрудник создаёт заявку → руководитель своей команды принимает решение → сотрудник видит историю и уведомление. HR имеет доступ на чтение.

## Endpoints
- `GET /api/requests/policy` — остаток отпуска и демо-лимит аванса.
- `GET /api/requests` — список с серверной фильтрацией по роли.
- `POST /api/requests` — создать (только employee).
- `GET /api/requests/{id}` — карточка и история (проверка доступа).
- `POST /api/requests/{id}/decision?approved=true|false` — решение (только руководитель команды).

### Отпуск
```json
{"type":"Отпуск","period":"автоматически","start_date":"2026-11-10","end_date":"2026-11-12","reason":"Семейные обстоятельства"}
```
Сервер считает **календарные** дни включительно, не доверяет переданным `days`/`period`, проверяет прошлые даты, остаток и пересечение с активными отпусками. Неподтверждённые заявки резервируют дни. Для UX клиент должен повторять проверки, но сервер остаётся источником истины.

### Аванс
```json
{"type":"Аванс","period":"автоматически","amount":50000,"reason":"Непредвиденные расходы"}
```
Демо-правила: целая сумма в KZT от 1 до 150000; причина обязательна; одна ожидающая заявка на аванс на сотрудника. Лимит — **демонстрационный**, не кадровая/расчётная политика Jańa Post. Утверждение не означает выплату. Поля `amount` и `currency` добавлены в ответ.

## Важно для фронтенда
**Фронтенд намеренно не менялся.** В текущей форме аванса отсутствует поле `amount`, поэтому до изменения формы сервер будет возвращать 422. Нужно добавить поле суммы и отображение суммы в карточке, запросить `/api/requests/policy`, сделать предпросмотр количества дней и проверку остатка до отправки. Для отпуска старый фронтенд совместим.

## Ограничения
Данные находятся в памяти процесса и сбрасываются после перезапуска; нет транзакционной БД, полноценного аудита, корпоративного SSO, интеграций с 1С:ЗУП/Documentolog, реального расчёта аванса или выплаты. Для продакшена нужны транзакции, отдельные политики компании, календарь отпусков, учёт уже использованных дней и механизм идемпотентности.
